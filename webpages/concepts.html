History of Computing

The microprocessor brings computing closer

The microprocessor brought a computer's central processing logic onto a single chip. As the technology developed, computers could become smaller and more affordable, helping computing move from large specialized machines into personal computers and, later, mobile and embedded devices. That shift helped make computing part of everyday life and laid important groundwork for the connected devices people use today.

Computer Systems

The input-process-storage-output model is easy to see while building this portfolio:

  1. InputI type and edit HTML and CSS using a keyboard and other controls.
  2. ProcessingThe browser reads the HTML and CSS, calculates the page layout, and prepares what to display.
  3. StorageThe website's code and images are saved as files in the project and repository.
  4. OutputThe browser renders those files as the page you can read and interact with.

Connected World

When someone visits this portfolio, their browser uses the domain name system (DNS) to find the site's IP address. The browser sends a request using HTTPS across the internet; network routers carry it to the server hosting the site. The server returns the website files, and the browser processes them to display the page. In this case, GitHub Pages hosts the published files from this project.

Cybersecurity Practices

The security habits I intend to apply to my own accounts and devices include:

  • Use a unique, strong password for each account and store passwords in a trusted password manager.
  • Enable multi-factor authentication (MFA), especially on email, cloud, and developer accounts.
  • Check the sender and destination address before opening links or entering credentials.
  • Install operating-system, browser, and application security updates promptly.
  • Be deliberate about what personal or account information I share publicly.

These habits connect to OPSEC: consider what information an action reveals, who could use it, and whether it needs to be shared.
